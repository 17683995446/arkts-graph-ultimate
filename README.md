# 🎯 ArkTS 代码知识图谱分析系统

> 百万行级 ArkTS → SQLite 代码知识图谱，动态更新，基于第一性原理设计

## 📋 概述

这是一个强大的静态代码分析系统，用于分析 ArkTS / TypeScript 项目，提取代码实体、调用关系和组件关系，并存储到 SQLite 数据库中，构建完整的代码知识图谱。

## 🚀 特性

- **高性能**：百万行级代码快速分析
- **完整图谱**：文件 → 类 → 方法 → 调用关系 → 组件关系
- **SQLite 存储**：关系型数据库，便于查询和分析
- **第一性原理**：优化设计，避免重复 I/O，真实分析
- **健壮性**：经过混乱场景、损坏语法等极端测试验证

## 🏗️ 核心架构

### 三层设计

1. **分析层**：ArkAnalyzer - 从源代码中提取实体
2. **集成层**：Python 层 - 处理 ID 映射，批量加载
3. **存储层**：SQLite 数据库 - 持久化知识图谱
